# 📜 Regras de Uso da Pasta Scratch

Para manter a organização e evitar redundância, as seguintes diretrizes devem ser seguidas ao criar ou utilizar scripts nesta pasta:

1. **Reutilização de Scripts:** NÃO criar um novo script para cada perfil se a ação for a mesma (ex: criação de perfil, update de senha). 
2. **Adaptação:** Em vez de novos arquivos, deve-se editar os scripts existentes, alterando apenas as variáveis necessárias (IDs, nomes, senhas, proxies).
3. **Nomenclatura Genérica:** Scripts devem ter nomes que descrevam a ação (ex: `create_profile_gold_standard.py`) em vez de nomes específicos de perfis, sempre que possível.
4. **Limpeza:** Scripts temporários ou de teste único devem ser removidos ou consolidados após o sucesso da operação.
